# Experience posts: an agent drafts, Victor approves

Status: accepted (2026-11-17, ticket experience-pages/01, A2)

An agent drafts each experience post from three sources: Victor's LinkedIn, the DocHelp article
(LinkedIn, 2026-04-22) and the repo history. After the design and the draft are done, the drafting
agent may ask Victor questions to fill gaps. Victor edits the text. A post ships only after Victor
approves its text.

**Why:** the cost of these pages is the writing, not the code. A draft from existing sources turns
that cost into an edit.

**Rejected:** Victor writes each post from scratch. It is slower, and pages would wait on a blank page.
