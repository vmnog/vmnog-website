# Experience row: expand, then a "Read the full story" link

Status: accepted (2026-11-17, ticket experience-pages/01, A3)

A click on an experience row on the homepage expands it in place, as it does today. When the role
has an experience page, the expanded paragraph ends with a "Read the full story →" link to that
page. A row without a page expands as today, with no link.

**Why:** one behaviour for every row. A click never does two things, and readers can still scan
the list without leaving the homepage.

**Rejected:** the row opens the page directly (rows would behave differently); a separate arrow icon
that opens the page (two targets in one row).
